# Quran Companion - download

Android app for learning to read the Quran (Tahsin), daily recitation (Tilawah), memorisation (Hifz) and tadabbur.
This page only holds the app file; it is not the source code.

## Download

**[Download the latest APK](https://github.com/mushaffarasyidridha/quran-companion-download/releases/latest/download/quran-companion.apk)** (about 130 MB, includes the recitation checker)

## Install (Android 8 or newer)

1. Open the link above on your phone and download the file.
2. Open the downloaded file. If Android asks, allow installing apps from this source (your browser or file manager) for this one time.
3. Open Quran Companion. To read together online: Home -> Halaqah keluarga -> Mulai, share the code, and the others tap Gabung and enter it.

Updating: download the newer file and install it over the old one; your data stays.

## Unduh (Indonesia)

1. Buka tautan unduhan di atas lewat ponsel Android (versi 8 ke atas), lalu unduh filenya.
2. Buka file yang diunduh. Jika diminta, izinkan pemasangan dari sumber ini (browser atau pengelola file) sekali saja.
3. Buka Quran Companion. Untuk membaca bersama online: Beranda -> Halaqah keluarga -> Mulai, bagikan kodenya, lalu yang lain menekan Gabung dan memasukkan kode itu.

Memperbarui: unduh file yang lebih baru dan pasang di atas yang lama; data tetap aman.

## Sources

Quran text: Tanzil (Uthmani). Translations: Saheeh International and Kemenag. Page layout and fonts: King Fahd Complex (KFGQPC) and Quran.com. Other riwayat text: King Fahd Complex. Recitation checker: Tarteel's Quran Whisper model, running on the phone. Audio: EveryAyah and mp3quran.net.
